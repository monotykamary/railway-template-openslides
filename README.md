# OpenSlides on Railway

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/openslides?referralCode=ZqgrJ0)

Deploy OpenSlides 4.3.1 as its official service-oriented stack with a generated `superadmin` password, private PostgreSQL and Redis, and daily database backups.

Sign in as `superadmin` with `SUPERADMIN_PASSWORD` from the backend-manage service. This is a large 14-service application intended for production meeting and committee management.

Upstream: https://github.com/OpenSlides/OpenSlides/releases/tag/4.3.1 (MIT). Not affiliated with Railway.
